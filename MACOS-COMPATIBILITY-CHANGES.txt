DSE ERP 2.1.3 - macOS UI and performance compatibility candidate

Changes:
- Responsive shell sizing based on actual JavaFX scene dimensions.
- macOS-specific spacing and font-metric overrides without changing Windows styling.
- Footer kept to a single compact line with ellipsis instead of consuming page height.
- Search, user menu and sidebar scale safely on Retina/logical resolutions.
- Expensive shadows removed from large macOS dashboard containers.
- Dashboard charts cached for faster Retina rendering.
- Header notification/email/WhatsApp/reminder polling reduced from every 2 seconds to every 15 seconds.
- All four header counters are read off the JavaFX Application Thread in one SQLite query.
- Major Add/Edit secondary windows now use the ERP shell as owner, WINDOW_MODAL behaviour and owner-centred placement.
- Version aligned to 2.1.3 in pom.xml and app-version.properties.

Local verification:
  mvn clean verify
  mvn clean package

Test on macOS:
- Dashboard at default and maximised window sizes.
- Add/Edit Item, Customer, Supplier and Master Data forms.
- Sidebar scrolling and footer allocation.
- Dashboard idle performance for at least two minutes.
- Dark and light themes.
