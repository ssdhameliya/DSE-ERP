# DSE ERP 7.3.2 — Unified UI, Permission, Footer and Reminder Stabilization

This same-version refresh is based on the supplied 7.3.2 Branding Asset Reliability baseline.

Implemented scope:
1. Settings outer gutters and clipped 5:1 Application Brand preview.
2. Sales-style Role Management and Permission Matrix identity headers.
3. Permission Matrix module filtering plus current-module permission catalog alignment. Built-in ADMIN/MANAGER/SALES role identities remain protected.
4. Unified two-panel authentication/startup shell for Splash, Login/Forgot Password, Registration and Email/OTP Setup.
5. One authoritative MenuButton/ComboBox/context-menu geometry contract; user menu and Actions controls no longer intentionally truncate.
6. Communication Center uses an icon + Re-send button.
7. Shared TableView policy expands readable columns, keeps Actions visible and consumes unused right-side width.
8. One SharedApplicationFooter component is used by the five standalone authentication/startup experiences and the logged-in Dashboard shell; all hosted application modules inherit that same footer.
9. Reminder Add/Edit/Delete/Complete/Reopen/Snooze now provide validation, confirmations and success feedback.

No version bump: 7.3.2.
