DSE ERP 2.1.5 - Phase 1 Shared UI Framework

Baseline: GitHub main v2.1.4

Added shared components:
- SharedUiFramework
- SemanticIconManager
- ActionMenuBuilder
- ToolbarBuilder
- FilterBarBuilder
- KpiCardBuilder
- DialogBuilder
- StatusBadgeFactory

- ProfessionalUiEnhancer now installs the shared framework for every loaded page.

- Existing Windows/macOS window, navigation, monitor, dialog ownership and
  responsive behavior are preserved.
