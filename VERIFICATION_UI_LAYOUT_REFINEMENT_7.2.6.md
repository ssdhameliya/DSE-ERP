# DSE ERP 7.2.6 UI Layout Refinement

Scope only; application version remains 7.2.6.

- Settings Company & Billing now groups Application Brand Image, Company Logo and Authorized Signature in one Brand & Identity Assets panel.
- Safe Rollback content no longer has a 1500px maximum-width cap and expands to the available page width.
- Safe Rollback cards/metrics/tables are larger and use the full panel width.
- Candidate and Activity tables use responsive proportional column sizing on window/layout width changes.
- Existing rollback business logic, database-preservation rules and full-recovery navigation are unchanged.
- Existing Sales and Purchase transaction/PDF routes were not modified by this UI refinement.
