DSE ERP 2.1.3 - GitHub Apply Package

Use this package only after the IntelliJ/local package passes your tests.

1. Keep your existing Git repository and its hidden .git folder:
   D:\GitHub\DSE-ERP\.git

2. Copy the CONTENTS of this package into:
   D:\GitHub\DSE-ERP
   Choose Replace files when prompted.

3. Verify locally:
   cd "D:\GitHub\DSE-ERP"
   mvn clean verify
   mvn clean package

4. Review:
   git status
   git diff --stat

5. Commit and publish only after testing:
   git add .
   git commit -m "Improve macOS responsive UI, modal dialogs and dashboard performance for DSE ERP 2.1.3"
   git pull --rebase origin main
   git push origin main

6. Release after Build and Test is green:
   git tag v2.1.3
   git push origin v2.1.3

Never replace the whole D:\GitHub\DSE-ERP directory and never delete its .git folder.
