DSE ERP 2.1.3 - IntelliJ / Local Test Package

1. Extract this package to a NEW test folder, for example:
   D:\JavaProject\DSE_ERP_2_1_3_MAC_TEST

2. Open that folder in IntelliJ as a Maven project with JDK 21.

3. Run these commands from the project root:
   mvn clean verify
   mvn clean package

4. Run org.example.app.Launcher with VM option:
   --enable-preview

5. Test on Windows first, then install the GitHub-built DMG on macOS after publishing.

Important tests:
- Dashboard at normal and maximised sizes.
- Dark and light themes.
- Add/Edit Item, Customer, Supplier and Master forms.
- Footer remains one line.
- Header controls do not overlap or truncate excessively.
- Leave Dashboard idle for two minutes and confirm smooth UI response.
- Notifications, email, WhatsApp and reminder badges still refresh.

Do not copy this whole folder over D:\GitHub\DSE-ERP. Use the separate GitHub Apply package for that repository.
