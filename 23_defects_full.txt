### Category 1: Performance & Screen Latency

#### 1. Cold-Start Latency on Secondary Transaction Screens (Quotation, Delivery Challan, Inventory)
- **Severity:** Medium
- **Location:** [QuotationEditor.fxml](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/resources/fxml/pages/QuotationEditor.fxml), [Inventory.fxml](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/resources/fxml/pages/Inventory.fxml)
- **Defect:** While Sales and Purchases cold-start was resolved in `10.0.28` via background pre-warming, opening Quotation Editor or Inventory for the first time still blocks the JavaFX UI thread while parsing dense FXML hierarchies and loading category/item masters.
- **Fix:** Extend `NavigationManager.prewarmScreenAsync()` to include Quotations and Inventory in the background pool.

#### 2. Dashboard Home KPI Live Aggregate Query Load
- **Severity:** Medium
- **Location:** [DashboardHomeController.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/controller/DashboardHomeController.java), [BusinessOperationsService.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/server/src/main/java/org/example/server/operations/BusinessOperationsService.java)
- **Defect:** Every time the user navigates back to the Dashboard Home screen, the server executes multiple live full-table aggregate scans (`COUNT(*)`, `SUM(total_amount)`, `SUM(paid_amount)`) against PostgreSQL without micro-caching (TTL 30–60s). On databases with 50,000+ invoices, this causes perceptible delay.
- **Fix:** Add a 30-second Redis/Caffeine TTL cache on dashboard KPI metrics.

#### 3. Table VirtualFlow Micro-Stutter on Rapid Window Resizing
- **Severity:** Low
- **Location:** [DynamicTableLayoutManager.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/util/DynamicTableLayoutManager.java)
- **Defect:** Rapidly dragging or maximizing the desktop window can trigger multiple cascading layout passes in JavaFX VirtualFlow for tables with custom button cell renderers (Action buttons, Status badges).
- **Fix:** Debounce the resize listener in `DynamicTableLayoutManager` with a 50ms pause before firing the final column width reflow.

### Category 2: Financial & Accounting Edge Cases

#### 4. Multi-Line Tax Rounding (1-Paisa Roundoff Edge Case)
- **Severity:** High
- **Location:** [SalesController.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/controller/SalesController.java), [BusinessOperationsService.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/server/src/main/java/org/example/server/operations/BusinessOperationsService.java)
- **Defect:** Line-item tax amounts are rounded to 2 decimal places per line item. In multi-item invoices (e.g. 20+ lines), the sum of rounded taxes can differ by ₹0.01 or ₹0.02 from calculating tax on the aggregate taxable total.
- **Fix:** Implement explicit `Round-Off` adjustment line item adhering strictly to Indian GST Rule 26.

#### 5. GST Zero-Tax Classification Ambiguity (Nil-Rated vs Exempted vs 0%)
- **Severity:** Medium
- **Location:** [ItemEntity.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/server/src/main/java/org/example/server/persistence/entity/ItemEntity.java), [SalesTaxInvoiceService.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/invoice/service/SalesTaxInvoiceService.java)
- **Defect:** Items with 0% tax are stored simply with `gstPercent = 0.0`. Under Indian GST GSTR-1, filings require distinguishing whether an item is "Nil Rated", "Exempted", or "Non-GST Supply".
- **Fix:** Add a `gstSupplyType` enum column (`TAXABLE`, `NIL_RATED`, `EXEMPT`, `NON_GST`) to `item_master`.

#### 6. Manual Credit Note / Return Balance Settlement
- **Severity:** Medium
- **Location:** [SalesReturnService.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/server/src/main/java/org/example/server/returns)
- **Defect:** When a Sales Return (Credit Note) is approved, it creates a credit entry. However, the system does not automatically adjust or offset open unpaid invoices for that customer via FIFO, requiring manual payment adjustment.
- **Fix:** Provide a "Quick Apply Credit Note to Outstanding Invoices" action dialog.

#### 7. Partial Payment Status Inaccuracy on Reconciled Cheques
- **Severity:** Low
- **Location:** [BankReconciliationService.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/server/src/main/java/org/example/server/reconciliation/BankReconciliationService.java)
- **Defect:** If a cheque payment is marked "PDC" (Post-Dated Cheque) or "Under Clearing", the invoice shows as "PAID" before the bank statement allocation has confirmed clearance.
- **Fix:** Mark status as "CLEARING_PENDING" until bank reconciliation statement matches the voucher.

### Category 3: Concurrency & Multi-User Edge Cases

#### 8. Sequence Number Gap on Discarded Invoices
- **Severity:** High
- **Location:** [BusinessOperationsService.java:710](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/server/src/main/java/org/example/server/operations/BusinessOperationsService.java#L710)
- **Defect:** When opening "New Sale", the frontend requests `nextSaleInvoice()`, which advances the `reference_counter` table. If the user cancels or closes the window without saving, that invoice number is skipped, creating a gap in sequential numbering.
- **Fix:** Only allocate the permanent sequence number on final **Save/Commit**, while using `previewSalesInvoice()` during form drafting.

#### 9. Concurrent Edit Conflict Experience
- **Severity:** High
- **Location:** [OperationsApiClient.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/api/operations/OperationsApiClient.java)
- **Defect:** If User A and User B open the same invoice, and User A saves first, User B receives an uninformative error dialog: *"Record was modified by another user (RowVersion mismatch)"*, and User B's edits can only be discarded without a merge or difference viewer.
- **Fix:** Show a conflict comparison dialog showing what changed and allow User B to overwrite or save as a revised copy.

#### 10. Multi-Tab Party Master Deletion Foreign Key Lock
- **Severity:** Low
- **Location:** [MasterDataService.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/server/src/main/java/org/example/server/master/MasterDataService.java)
- **Defect:** Deleting a Customer or Supplier that is linked to historical invoices throws a raw SQL `DataIntegrityViolationException` (foreign key constraint) instead of a clean, user-friendly prompt: *"Cannot delete party: 12 invoices are linked. Would you like to deactivate instead?"*
- **Fix:** Wrap FK constraint check in `MasterDataService` and suggest soft-deactivation.

### Category 4: Document Studio (PDF & Excel) Defects

#### 11. Long Description Text Overflow in PDF Line Items
- **Severity:** High
- **Location:** [PdfStudioRenderer.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/documentstudio/service/PdfStudioRenderer.java), [UniversalPdfEngine.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/documentstudio/engine/UniversalPdfEngine.java)

#### 12. Non-Latin / Regional Indian Font Character Missing Glyph
- **Severity:** Medium

#### 13. Dynamic Formula Refresh in Excel Studio Export

### Category 5: Import / Export & File System Edge Cases

#### 15. Large Spreadsheet Import Heap Spike (DOM vs SAX Parser)
- **Severity:** High
- **Location:** [ImportService.java:416](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/service/ImportService.java#L416)
- **Defect:** Excel import loads the entire `.xlsx` into memory via Apache POI `XSSFWorkbook`. Importing files with >10,000 items or multi-year historical data consumes over 500 MB RAM and can trigger `OutOfMemoryError` on 4GB client systems.
- **Fix:** Migrate to event-driven streaming reader (`StreamingReader` / POI SAX).

#### 16. Cross-Platform Attachment File Paths (Windows `\` vs Linux `/`)
- **Severity:** Medium
- **Location:** [OperationsApiClient.java:88](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/api/operations/OperationsApiClient.java#L88), [SettingsAssetService.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/service/SettingsAssetService.java)
- **Defect:** Attachment relative paths saved from a Windows client contain backslashes (`attachments\sales\inv.pdf`). If the server runs on Linux (as in UAT/PROD Docker containers), path resolution fails unless normalized.
- **Fix:** Use `FilenameUtils.separatorsToUnix(path)` before saving to database.

#### 17. Unsanitized File Names on Invoice Export
- **Severity:** Low
- **Location:** [DocumentOutputService.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/documentstudio/service/DocumentOutputService.java)
- **Defect:** If an invoice number or party name contains special characters (`/`, `:`, `*`, `?`), saving to disk without sanitizing triggers an `InvalidPathException` on Windows.
- **Fix:** Sanitize default filenames using `name.replaceAll("[\\\\/:*?\"<>|]", "_")`.

### Category 7: Security & Administration

#### 21. Automated Backup Retention & Disk Pruning
- **Severity:** Medium
- **Location:** [BackupManager.java:263](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/backup/BackupManager.java#L263)
- **Defect:** Safety backups created during restore/updates accumulate indefinitely in the backup folder if the system admin has not configured a strict retention script, gradually consuming disk space.
- **Fix:** Automatically prune local safety backups older than 30 days while retaining the latest 5 snapshots.

#### 22. Session Inactivity Timeout Form Data Loss Prevention
- **Severity:** Medium
- **Location:** [SessionActivityManager.java:185](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/desktop/src/main/java/org/example/service/SessionActivityManager.java#L185)
- **Defect:** When the 10-minute inactivity timer locks the screen, unsaved invoice lines remain in memory. If the user closes the modal or logs in as a different user, unsaved lines are cleared without an automated local recovery draft.
- **Fix:** Persist an auto-recovery draft in SQLite/local JSON before executing idle logout.

#### 23. In-App Audit Trail Log Query Pagination on Long Date Ranges
- **Severity:** Low
- **Location:** [AuditLogService.java](file:///c:/Users/JATIN%20DHAMELIYA/Downloads/DSE-ERP-10.0.25-INTELLIJ-READY-FINAL-V19/DSE-ERP-10.0.25/server/src/main/java/org/example/server/audit)
- **Defect:** Querying the Audit Trail screen for "All Time" without selecting a specific entity type loads all audit rows into memory, causing table lag on databases with years of audit logs.
- **Fix:** Enforce a default 100-row page limit with server-side pagination on the Audit Trail screen.
