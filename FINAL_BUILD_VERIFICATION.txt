FINAL LOCAL -> EXISTING SERVER SAFETY
- New PCs retain the choice: Local workspace OR Shared / Company Server.
- Shared Client uses application-managed client storage; the user does not choose/create a business workspace.
- Existing LOCAL -> Connect to Existing Server writes a separate managed Shared Client profile.
- Original LOCAL Config/config.properties is preserved byte-for-byte for rollback.
- The connect-existing-server Save operation is deployment-only and does not push local company,
  email, storage or business settings to the already-existing server.
- DSE ERP closes immediately after the LOCAL -> Shared switch to prevent a mixed-runtime session.
- Local database, attachments/documents and local company data are not uploaded by this path.
- Promotion remains a separate Local -> Server promotion workflow.
- The Local-company confirmation uses clear choices: Connect to Existing Server switches this PC to Shared Client; Cancel keeps the PC local. Legacy “Enable Multi-User” wording was removed from this user-facing warning.
