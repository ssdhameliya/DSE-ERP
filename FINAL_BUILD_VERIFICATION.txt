DSE ERP 9.0.76 - AUTOMATIC WORKSPACE RECOVERY

Release scope:
- A saved valid workspace now starts automatically even when an older Config/config.properties file has setup.completed=false or no setup.completed marker.
- Startup no longer opens the workspace/setup chooser solely because the local setup marker is missing or stale.
- PostgreSQL/Spring services remain authoritative for setup state. If the server confirms the company database is already initialized, DSE ERP repairs only the local setup.completed marker and continues to Login.
- The Setup Wizard remains available for genuine first-time setup when no saved workspace exists or when the initialized server truly reports that setup is required.
- Settings -> Workspace & Storage continues to provide Select Existing Workspace and Move Workspace for deliberate workspace management.
- All 9.0.74 import reliability, dialog semantics, immediate feedback, PDF Studio behavior, Project Execution removal and the two-theme UI architecture are preserved.
- No database schema migration is required for 9.0.76.

- JavaFX 25.0.2
