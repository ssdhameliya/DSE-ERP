DSE ERP 9.0.73 - PDF STUDIO ACTIVATION & TEMPLATE DELETION RELIABILITY

Release scope:
- PDF Studio Publish / Set as Default sample validation now supplies realistic Item Master remarks required by the shared Standard Sales PDF layout.
- GST/IGST sample validation remains restricted to supported calculation tax modes; business-treatment labels such as Registered Business are not used as tax modes.
- The mapped DS Engineers Sales starter can be intentionally deleted and stays deleted across PDF Studio refresh/list operations.
- The existing Jasvi built-in Sales template keeps its intentional-delete marker and legacy Sales PDF fallback behavior.
- Settings → Workspace & Storage → Select Existing Workspace from 9.0.72 remains unchanged.
- Portable PDF Studio import/export, dynamic Sales PDF layout, Project Execution removal and the two-theme UI architecture remain protected by release gates.
- No database schema migration is required for 9.0.73.

Release evidence is distributed separately from the clean IntelliJ/GitHub source copies.
